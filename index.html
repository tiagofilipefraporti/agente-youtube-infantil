Agente YouTube Infantil

Ferramenta de uso pessoal que publica histórias infantis originais e narradas no canal do próprio autor no YouTube.

O aplicativo usa a API de dados do YouTube só para enviar e agendar vídeos no canal do dono da ferramenta. Ele não é oferecido a outros usuários e não acessa dados de terceiros.
