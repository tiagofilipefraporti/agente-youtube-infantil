Política de Privacidade — Agente YouTube Infantil

Última atualização: 11 de novembro de 2026

O que o aplicativo faz

O Agente YouTube Infantil é uma ferramenta de uso pessoal. Ela envia e agenda vídeos no canal do YouTube do próprio dono da ferramenta, usando a API de dados do YouTube com a permissão youtube.upload.

Dados acessados

O aplicativo não coleta, vende nem compartilha dados pessoais. Ele só usa o token de autorização que o Google entrega ao dono do canal para enviar vídeos a esse canal. O token fica guardado apenas no computador do dono e nunca é enviado a terceiros.

O aplicativo não acessa dados de espectadores, comentários, contatos nem nenhuma outra informação da conta Google.

Uso das APIs do Google

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado. Ao usar o aplicativo, você também concorda com os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Como revogar o acesso

A autorização pode ser revogada a qualquer momento em myaccount.google.com/permissions.

Contato

Dúvidas podem ser enviadas ao e-mail de suporte exibido na tela de consentimento do Google deste aplicativo.
